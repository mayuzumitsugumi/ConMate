# 財務公式與核對契約

## 計算與決定

函式返回 `{ status: complete|partial, values, unknownItems, warnings, sources, ruleVersion }`。不知道的數字是null；不以0、空字串或自行規則掩蓋。使用者可在partial時記錄人工分配或結案。資料錯誤仍拒絕不合法命令。

「實際經濟成本」「內部約定回收」「實際現金」各有來源。庫存未售成本不等於已售成本；回收額不等於利潤；投入未回本不必然是他人的欠款。

## 精度與取整

1. 輸入整元款項：非負整數元；沖回與人工往來使用有方向的整數。
2. 單價／每件回收額最多4位；比例百分比最多4位，例如20.0000%。
3. 內部用BigInt固定尺度加精確分數，不用JavaScript浮點數算錢。
4. 分攤保存分子、分母與來源總額；顯示4位不代表丟棄精確分數。
5. 獨立最終值四捨五入，恰半遠離零。拆分整元用最大餘數法：先對總額絕對值分配整數，再把剩餘元按餘數由大到小分配，餘數相同依穩定ID升序；負總額最後恢復符號。
6. 成本／回收／費用／抽成以同一來源及規則版本累計：本次應計＝本截止累計應計−先前已認列。退款用原來源重算差額，不另套新規則。

## 柄圖分攤

柄圖費A、品項i、基準數量q_i、單件成本基準p_i：

- 單件成本權重：A_i=A×p_i/Σp。
- 製作總成本權重：A_i=A×p_i×q_i/Σ(pq)。
- 品項平均：A_i=A/n。
- 總件數平均：A_i=A×q_i/Σq。
- 自訂權重：A_i=A×w_i/Σw。
- 人工指定：ΣA_i=A，否則資料錯誤。

精確單件柄圖成本a_i=A_i/q_i；實際單件製作成本c_i=實際批次費/Q_i；綜合成本=c_i+a_i。

p_i採預估、實際或內部約定需明確指定。分攤群組固定其參與品項及基準數量；不能新批次加入就再扣完整A。

約定每件回收r_i獨立保存。預計差額Σ(r_i×q_i)−A，差額歸屬未設定則只列unknown/warning。系統不擅自封頂、不擅自增加本金、不阻止人工結案。

## 收入、成本、抽成

R=成交總額−行折扣−整單折扣−退款。行折扣及整單折扣各扣一次；後者按行折扣後的金額比例分配整元。抽選依實際獎品分配實收，不能按整個池平均所有商品。

實際銷售毛利=R−已售實際製作成本−已售精確柄圖成本。共通費用及報廢另列，不混入未定義「淨利」。

可分配基礎B=R−規則指定成本−被指定先扣的固定費。成本口徑、固定費先後、負值政策、分配者缺一則該項partial，不暗中默認。

| 模式 | 公式與流向 |
| --- | --- |
| 自付製作，只交柄圖費 | 創作者分配R−已售約定柄圖回收；自付製作成本仍列損益，不再扣現金 |
| 扣柄圖後抽成 | F=(R−已售約定柄圖回收)×比例；創作者分配=R−柄圖回收−F |
| 營收比例抽成 | F=R×比例；指定成本回收另照約定，不默認扣 |
| 扣指定成本抽成 | F=B×比例；被扣成本回收與B−F分配分開，回給有權回收者 |
| 固定費 | 金額、每件／筆／場／企劃、收費時點、退款政策皆明定 |

負基礎可選最低零、按比例承擔、人工決定；沒設定不自行算負抽成。退款仍須沖回原抽成，即使新銷售政策最低為零。

同一來源只能匹配一套主規則；特殊方案要明確排除或覆寫一般規則。可疊加費用需明列順序及各自基礎；禁止兩條模糊重疊規則默默同扣。

## 付款、內部負擔及代墊

付款記真實payer→payee。內部負擔可以不同，但差額另有對象、成立與收取時間。

本金僅建立在已付且可追收的投入：未還本金=原本金+增加−沖減−償還−明確免除。成本回收已抵本金時不能再抵一次。抽成承擔不追收投入只做回本分析，不自動建創作者應付。

銷售分配→依約定順序抵付→應收應付→實際付款。沒設定抵付順序不自動扣。每筆抵付有唯一來源，回收不是銷售收入、還本金不是新費用。

用戶這次立牌案例只收實付1368（預估1710）；342是預估差異，不是團費或本金。未來另約保留會員折扣，需獨立內部計價，不改實際廠商成本。

## 無料、退貨、領回及回本

無料／損耗有成本沒銷售；由誰負擔未知則列待定。退貨回原出庫成本；損壞與退款分開。結案可只針對領回品或整體合作，沒有規則仍可人工決定，保留未結清餘額。

結案不自動認列未售全部虧損、免除代墊或追收原投入。存貨保留／報廢／作價領回分開記。

單品簡單損益平衡：固定投入/每件邊際貢獻向上取整；貢獻≤0顯示無法在該條件回本。整批製作費作固定投入時，不能再作單位變動費重複扣。混池與多價格要明列情境及銷售組合，不提供憑空唯一回本件數。

## 核對等式

- 商品收入分配合計＝交易淨額。
- 費用分配合計＝費用來源額。
- 付款用途合計≤付款；未分配款單列。
- 期初存貨成本＋新增−已售−免費／損失／領回＝期末成本。
- 期初未還＋新增−回收−調整＝期末未還。
- 分配來源＝各方分配＋明列保留／不足。
- 期初往來＋成立−抵扣−清償＝期末往來。
- 期初持款＋實際流入−實際流出＝期末持款。

人工分配若偏離等式可保留決定，但必須列明差額，不偽造營收或付款配平。內部抽成與團務移轉合計時排除重複收入。

## 已知數值來源

finance.json中origin=provided-workbook的數值摘自使用者工作表，不假設尚未提供付款人或分潤。origin=confirmed-conversation是先前確認例。origin=synthetic是純驗證向量，不套用為用戶合作預設。

完整原表不加入repository，未保存折扣碼、儲值餘額或與驗收無關的個人資料。精確預期用分數字串，避免把顯示近似值當正式來源。
