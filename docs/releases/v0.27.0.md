# v0.27.0：寄賣交付與對帳

創作管理新增寄賣作業，分開處理交付實物、店家售出回報與實際收到店家款項；這不是短期活動交接，也不會實際轉帳。

- 指定寄賣店參與方後建立專用庫位。交付與收回採現有庫存調撥，保留批次及指定單件，總庫存不因交付增加。
- 店家已確認售出的商品按實際時間、數量及單價登記，產生一次銷售及扣庫。店家售出不等於創作者已收到款項。
- 顧客退款與可售／損壞退貨分開記錄；可售品先回寄賣庫位，實物收回另行確認。
- 一般庫存、攤位販售、方案預留與活動交接不能直接挪用寄賣專用庫位。
- 實際寄賣費及人工調整額需明確填寫；空白代表未知，確認沒有費用或調整才填0。本版不預設佣金比例，也不自動套用抽成。
- 核對目標＝店家銷售額－退款額－明確費用＋人工調整。實際匯回款項另行登記，可分次收款並沖銷誤記；實收不是第二筆營收。
- 對帳差額及剩餘庫存可保留待查，使用者仍能結束寄賣並明確重新開啟；既有歷史保留。
- 營運報表列入已確認的寄賣銷售；顧客現金表不把店家收款冒充創作者現金，也不把店家匯回款重複加進顧客收款。

完整備份升至schema21／Dexie22／Excel2.19，舊備份安全升級。寄賣資料不加入無關活動檔，也不透過主資料匯入修改。

## 範圍限制

- 本版為人工登記店家回報，沒有寄賣平台API、報表自動抓取或實際金流。
- 店家回報的實際售出時間與系統登記時間用途不同；補登不會重新排序既有庫存歷史或猜測舊成本版本。
- 本版先核對店家實際匯回的收款；負差額不自動產生向店家付款、欠款或代墊。
- 長期寄賣可明確追加交付，不受短期活動固定交付量或兩週原則限制。
- 預售、訂金、尾款及預售交付仍為下一階段。
