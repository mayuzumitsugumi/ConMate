# v0.11.0：分次退款、退貨與換購關聯

- 逐項記錄實際已退金額、可售回庫及損壞退回數量；金額和退回商品分開，不假設一定相同。
- 支援只退款不退貨、零元商品退回及分次處理；累計退款不可超過原成交金額，退回數量不可超過原售出數量。
- 可售商品回到明確選擇的庫位；損壞退回保留數量紀錄，不增加可售庫存。
- 原交易及退款歷史不可覆寫，重送同一操作不重複退款或回庫。
- 換購以退款紀錄連結新的交易，兩筆實際款項各自記錄，不自動假設或沖抵差額。
- 舊版整筆全退仍保留；已有分次退款／退貨的交易不能再用舊整筆取消，以免重複回庫。
- 場次摘要與財務營收納入部分退款，代墊與利潤仍分開。
- schema10／Excel2.8，舊檔安全升級補空退款紀錄。
