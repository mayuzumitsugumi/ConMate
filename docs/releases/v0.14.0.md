# v0.14.0：分潤試算、人工決定與實際往來核對

## 明確規則與來源

- 可為不同商品、方案、場次或合作另建結算工作單，明確選取銷售明細與製作成本。選取的是整批成本，不是系統推算的已售成本；未選成本不代表零成本。
- 可選營收或扣除選取成本後的金額作抽成基礎；抽成比例、固定管理費、固定費順序、負基礎處理及各對象比例均需明確填寫，無費用需填0。比例最多四位小數。
- 規則或成本不完整則保存「尚無法完整試算」與原因，不擅自補零。所有試算保存當時來源、規則與結果，後續來源變更不改寫舊快照。
- 可分配來源＝選取的退款後營收－選取的精確成本。管理費與抽成按明確順序計算，餘額再依比例分配；BigInt分數計算，整元尾差以穩定ID核對，合計守恆。
- 重複試算不產生收入、扣款或付款；跨工作單來源重疊會警告，不自動重複扣成本。

## 人工決定與實際款項

- 人工分配是整份累計目標，新決定取代前次目標但保留歷史。可與試算不同，須說明原因；沒有完整試算也能自行決定。
- 實際付款另行記錄付款人、收款人、金額及確認，分次付款持續累計，不因新增決定而歸零。登錄錯誤以有來源的沖銷更正。網站不會實際轉帳。
- 期初持款由使用者明確登記；未填表示未知，不由收款者推定利潤歸屬。既有退款沒有付款人資訊，不能自動推算誰手上有多少錢。
- 工作單以外的實際現金增減可明確登記，例如由某人支付客人退款；它只影響持款核對，不自動新增成本、營收或代墊。不要重複登記已計入期初持款或工作單內轉款的款項。
- 應收／應付差額＝最新人工累計目標－期初持款－外部現金淨增加－工作單內淨收款。缺期初資料則列未知，仍可記錄實際款項。
- 使用者可在規則缺漏、虧損、未付清或差額待查時結束工作單；可明確重新開啟追加決定，關閉／重開歷史與已付款都保留。

## 相容性與範圍

資料schema12／Dexie13，Excel格式2.10.0；舊備份與本機復原點安全升級。分潤、決定及款項保存在同一專案檔中。

本版沒有自動套用商品規則優先序、跨工作單自動抵付、雲端轉帳或正式會計帳；代墊本金與其償還不會自動扣進利潤。

驗證：173項單元測試、12項契約檢查、型別檢查、建置與34項桌面／手機端對端流程通過。案例覆蓋比例精度、整元尾差、來源變更快照、退款後持款、人工改版、實付沖銷、未知規則仍可決定與結案、舊版升級及完整專案往返。
