# v0.8.0：攤位販售與基礎財務

剩餘兩個入口新增第一批可用功能，所有資料保存在同一工作區及專案檔。

## 攤位販售

- 選擇出貨庫位、場次與實際收款者，快速加入指定購買或已知實際款式的抽選結果。
- 每項數量及單價明確輸入；收款不足時不成交，收到金額、應收及找零分開。
- 成交與實際SKU扣庫同一原子交易；指定／抽選共用一份實物庫存，重送操作不重複記帳。
- 支援整筆全額退款並全數回到原庫位，新增沖銷紀錄、保留原成交，不能從庫存頁單獨改動販售出庫。
- 購物車尚不保留庫存，離開頁面後不保留未成交草稿。

尚未提供抽選池設定、部分退款、換貨、損壞退貨與FIFO批次分配。

## 成本與財務

- 每個商品可建立多筆製作批次成本，分開記錄預估／實際印製費、人工指定柄圖分攤額、其他成本及試算售價。
- 空白表示未知，確定無費用才填0；資料不完整時顯示尚無法試算。
- 使用BigInt與精確分數計算成本、單件成本、全部售出預估毛利及回收整批成本所需銷量，單件成本最後以四位小數顯示。這些是試算，不等於實際已實現毛利。
- 成本紀錄不產生付款或庫存。付款者／負擔者註記不自動建立欠款。
- 另行登記已實付且約定可追收的代墊本金、分次實際償還、還款沖銷及無有效還款的代墊作廢；本金償還不是利潤或費用。
- 可分配利潤維持尚無法試算；自動柄圖分攤、管理費、抽成、分潤結算與完整款項對帳仍待開發，不替使用者決定追收與結案。

## 保存與相容性

Dexie/schema升至7，既有資料與ID原樣保留，只補空交易／成本／代墊清單。Excel格式2.5.0新增09～13日常表，完整歷史仍在同一檔案。還原支援2.1.0～2.5.0，檢查收款、交易出庫、退款回庫與代墊還款關聯。
