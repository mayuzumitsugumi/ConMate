# v0.19.0：批次成本連結與已售成本核對

- 成本與財務新增批次連結區，明確選取「製作入庫」來源及同商品、同數量的成本紀錄。整批成本不能重複分配到不同入庫；分批入庫需先明確分開成本紀錄。舊來源未知庫存不推算製造成本。
- 每次設定保存不可改寫的精確成本快照與生效異動截止點；成本修改或重新連結只影響之後出庫，之前銷售維持當時版本或未知。可明確解除之後成本連結，歷史仍保留。
- FIFO 銷售成本按實際來源分配，不採目前平均成本；使用 BigInt 分數合計後才顯示四位小數，未知數量另列，不當作零。
- 可售退貨按原銷售版本反向核對成本，僅退款但沒回庫不沖回成本。損壞退貨成本另列且不重複加總；「營收減未回庫成本」只是核對差額，不代表會計損失認列、負擔歸屬或可分配利潤。
- 現存批次成本依目前明確版本顯示參考估值，不建立重估會計分錄。連結不新增庫存、付款、代墊或結算，分潤工作單仍由使用者明選整批成本，不自動改套已售成本。
- schema15／Dexie16／Excel2.13，新增34_批次成本版本與35_已售成本核對。舊備份及本機復原點升級只補空版本，歷史金額與 ID 不改。

驗證：215項單元、12項契約、44項桌面／手機流程，覆蓋不同單價FIFO、成本版本、連結前未知、部分退款／可售與損壞退貨、跨庫調撥、整批成本重複連結拒絕、升級／專案往返及精確尾數。

尚未支援一筆製作成本直接分配到多筆入庫、回填舊銷售成本的正式更正、正式會計或自動分潤成本套用。
