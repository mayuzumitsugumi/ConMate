# v0.20.0：內部計價、約定回收與差額歸屬

成本與財務頁增加獨立內部約定，分開核對來源成本、成員負擔、約定回收與實際收到的款項。

- 以商品製作成本或柄圖費作來源，保存當時精確成本快照。內部負擔總額、回收規劃數量、最多四位小數的每件約定回收額由使用者明確填寫；空白是未知，0必須明確輸入。
- 分別顯示內部負擔與來源成本差額、全部約定回收與來源成本差額。差額歸屬與處理說明可保留待確認，不自動當成團費、收入、利潤或欠款。
- 廠商實付仍使用既有費用付款紀錄；內部約定不會建立付款、庫存、代墊本金或分潤扣款。
- 成員間已實際收到的內部回收另外登記付款人、收款人、金額及原因；不是顧客銷售收款。實收可高於約定，差額列待核對，不自動歸屬。
- 新約定版本保存同一來源、保留原版本，實收按前版鏈累計，不能因換版本再次回收本金。登記錯誤透過沖銷更正，不刪歷史。仍有實收時不能作廢約定，但不限制工作區結案。
- 多份獨立約定共用來源時顯示警告，不自行分攤或將全額來源成本重複彙總。製作成本與柄圖費可能涵蓋相同費用，使用者須核對範圍。

## 案例與限制

- 預估1710、實際1368、內部負擔1368，不會自動產生342團費。
- 來源4000、約定30件每件134，規劃回收4020，差額20明確列出並等待指定處理。
- 本版手動記錄成員內部實收，未自動按顧客銷售回收，也未自動抵付代墊或跨結算工作單。相同現金不可另重複記作代墊還款或結算轉款。

資料schema16／Dexie17，Excel2.14.0新增36_內部計價約定、37_內部回收實收，完整版本與歷史包含在同一專案檔。舊備份只補空清單，不推定以前的約定、收款或差額歸屬。
