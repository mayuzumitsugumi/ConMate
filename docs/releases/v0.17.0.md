# v0.17.0：入庫批次與 FIFO 數量來源

- 每筆新入庫／調增建立獨立入庫批次，可填名稱，留白使用入庫編號。不同來源即使同名也不合併。
- 減少、無料、損耗、調撥及銷售從來源庫位按原入庫先後配貨；調撥不重設順序。
- 銷售、部分退貨及整筆取消保存並核對原批次；損壞退貨不增加可售庫存。
- 沖銷必須有原批次數量，不能以其他批次抵銷；原來源已售出／移走時先處理後續異動。
- 舊帳安全升級為「舊資料／來源批次未指定」，保留 ID、異動數量、款項及歷史，不推造舊製造批次。
- 庫存頁顯示各入庫批次／庫位餘額，同份 Excel 增加批次及批次異動表；schema13、Dexie14、專案格式2.11。

這是數量來源追蹤；成本表與入庫仍分開，不自動計算已售成本、推定歷史成本、預留庫存或追蹤特殊單件。尚未實作項目與後續順序見 implementation-roadmap.md。

驗證：192項單元、12項契約與40項桌面／手機端對端測試通過；涵蓋跨批次FIFO、調撥、原來源沖銷、部分可售／損壞退貨、歷史未知來源升級、不合法批次拒絕及單檔往返。
