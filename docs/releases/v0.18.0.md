# v0.18.0：創作者、柄圖與商品歸屬

- 新增「創作者與柄圖」分頁，獨立新增、編輯、封存及恢復參與方與柄圖。
- 參與方可代表創作者、總召、付款者、收款者或團體；只整理主資料，不建立帳號或權限。
- 柄圖作者可明確選一位或多位；不知道時留白，不由商品創作者推定。商品可選同企劃既有柄圖，讓多商品共用穩定柄圖 ID。
- 商品擁有者另行選擇，與商品創作者、柄圖作者、付款人及收款人分開，不自動產生欠款、分潤或轉帳。
- 改名保留 ID；封存保留既有關聯，禁止新商品／柄圖新增封存關聯。已連商品的柄圖不能直接換企劃，需另建並明確調整商品。
- 新的銷售明細保存當時創作者、擁有者與柄圖作者名稱及 ID，後來改名或修改商品不改寫舊快照。舊交易未記錄歸屬，不以目前設定回填。
- schema14／Dexie15／Excel2.12，舊資料及本機復原點升級時保持擁有者與柄圖作者未知，原有 ID／帳務不改。新增32_創作者與參與方、33_柄圖主檔可讀表，完整資料仍在同一檔。

本版一個商品可登記一個擁有者（可為團體）；多人權益比例及正式柄圖授權契約另待後續。批次成本及已售成本連結仍是下一項，不以商品歸屬推算利潤。

驗證：200項單元測試、型別檢查、建置及42項桌面／手機流程；涵蓋未知資料升級、封存保護、改名穩定性、新交易歸屬快照與專案往返。
