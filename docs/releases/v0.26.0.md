# v0.26.0：Excel 主資料匯入

「專案檔與備份」新增目前工作區專用的 XLSX 編輯範本，可新增或更新參與方、企劃、場次、柄圖、標記、自訂欄位與商品。

- 既有資料以穩定 ID 更新；同檔新增資料透過不區分大小寫的代號與 `new:代號` 參照，不按名稱或列號猜配。欄位選項以獨立的欄位新增代號欄連結。
- 純文字範本可維護單選／多選選項的名稱及封存狀態，保留商品原有選項 ID 與自訂值。既有資料缺列、未知 ID、重複代號、無效日期及參照會拒絕整份匯入。
- 先檢查並顯示新增／更新差異；確認後才以單一資料庫交易提交，錯誤可下載結構化 JSON 報告。不同工作區或下載後已變動的修訂不能套用，失敗不會部分寫入。
- 庫存、交易、退款、成本、代墊及結算不屬於編輯範圍；已用於交易的場次不能修改，場次／柄圖／標記／自訂欄位的封存狀態仍在網站操作。
- XLSX 在本機 Web Worker 解析，沿用完整備份的大小、展開量、公式、外部關聯、巨集及附件安全檢查。

完整專案仍為 schema20／Dexie21／Excel2.18，主資料匯入另使用格式 v1。完整備份及活動交接的還原方式不變；完整專案檔的日常閱讀表修改不會被還原採用。契約詳見[主資料匯入](../contracts/master-data-import.md)。

Excel／LibreOffice 實際重存往返、大量資料及實體手機驗收仍待補充；目前瀏覽器驗收使用 Chromium 桌面及手機尺寸。
