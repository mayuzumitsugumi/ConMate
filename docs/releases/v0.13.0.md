# v0.13.0：柄圖費分攤與費用付款核對

- 記錄柄圖費來源，依單件印製成本、印製總成本、平均、自訂權重或人工金額，分攤至使用同一柄圖的製作成本紀錄。不同製作數量分別計算單件回收額。
- 按所選預估或實際印製費作基準，缺值保持未知。以BigInt精確分數保留來源分攤，不以顯示小數反算。
- 另列整元分攤額供核對，最大餘數法以穩定ID處理尾差，合計等於原始柄圖費。單件成本、預估利潤與回本採精確來源分數計算。
- 生效中的分攤有來源及版本，不能重複分配；取代原人工柄圖額需要明確確認。撤銷保留歷史並恢復原人工值，修改基準前需先撤銷。
- 實際印製／其他費用／柄圖付款另行記錄，可分次支付與沖銷。顯示來源費用、已付款及差額，未知費用不當作0。
- 實際付款不自動形成代墊或營收；柄圖付款按來源核對，不把分攤額再當作另一筆應付。內部負擔與代墊仍另列。
- schema11／Excel2.9，保留舊專案及本機復原點相容性。

本版不自動決定管理費、抽成、分潤或結案。這些留在下一批功能，不把費用核對稱為完整會計帳。

驗證：145項單元測試（含資料修訂上限保護）、12項契約檢查、型別檢查與建置通過；32項桌面／手機端對端流程通過。原經費案例的4000元柄圖分攤精確分數與1368元折扣實付案例均有覆蓋。
