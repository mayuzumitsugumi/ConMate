# v0.9.0：販售方案與混合抽選池

- 預先建立指定販售與抽選方案，設定名稱、整元單價、可交付商品及適用場次。
- 抽選池可混合不同創作者與商品種類；系統不抽獎，由現場登記實際交付款式。
- 同商品可放入多個不同價格方案，共用同一份實體庫存，不因方案增加數量。
- 成交保留方案名稱、版本及實際單價；方案修改不改寫舊交易。
- 加入購物車後若方案改版、封存、商品或場次不符，提交時阻擋並提示重新選擇。
- schema8／Excel2.6，舊專案安全升級補空方案；完整方案與歷史保存在同一檔案。

不含系統隨機抽獎、保底、專用保留或號碼輪次管理。免費方案可填0元；實際交付才形成有效成交與扣庫。
