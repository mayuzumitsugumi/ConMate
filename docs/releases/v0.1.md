# v0.1：第一個可開啟的網站

## 已實作

- Vue 3、TypeScript strict、Vite、Hash 路由與 Pinia。
- 總覽及 Excel 資料中心；其他分頁是有說明的預留頁，不是完成的管理功能。
- 工作區名稱經應用狀態與 repository 寫入 Dexie／IndexedDB；失敗不顯示成功。
- 依66表契約產生空白及虛構範例XLSX，所有表可見、正式ID留白、數值與文字分型、無計算公式。
- Service Worker 預先快取網站與兩份模板、離線狀態、手動更新提示。
- Pages子路徑與Actions檢查／發布流程。

## 驗證

- 12項Python契約檢查。
- 6項Vitest：工作區保存／無效名稱、模板結構／純值／型別／參照／樣式。
- 6項Playwright：桌面與Pixel 7尺寸的建立／重開、分頁、下載及離線資源。
- TypeScript檢查與正式建置。
- npm production audit：0 vulnerabilities（執行當時結果）。

這不代表完整MVP、實體Android／iOS或LibreOffice相容性已驗收。CI環境仍需實際執行；本機端對端採系統Chromium。

## 明確限制

本版只保存工作區名稱，沒有商品／成本／交易／盤點輸入，不要存放唯一重要資料。模板沒有驗證匯入器，下載不是備份。範例132列是虛構建檔資料，沒有執行入庫、交易及分配。

T01已交付；本版完成T02主要骨架，以及T04、T11–14中支援首畫面及模板所需的部分。完整命令、鎖定／遷移、檔案安全驗證、完整往返及業務模組尚未完成。下一個優先功能是目前企劃的商品／柄圖與批次建檔。
