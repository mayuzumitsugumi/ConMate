# v0.16.0：自己的 GitHub 備份

新增選配的個人 GitHub 連接與手動雲端備份。基本功能仍免登入，資料仍先保存在本機。

- 使用者自行建立專用私有儲存庫及有期限、限定該儲存庫 Contents 讀寫的 fine-grained personal access token。
- 介面清楚標為個人權杖連接，不是假稱 OAuth 登入。權杖只留在當前頁面記憶體，離開、重新整理或斷開後清除。
- 上傳前顯示目的、工作區、來源修訂與遠端摘要，使用者確認後才提交。
- 遠端版本或分支在預覽後變更時停止，不強制覆蓋，不合併裝置分歧。
- 遠端備份及歷史版本可下載並經相同安全檢查，進入既有還原差異預覽；確認前不寫入本機。
- 成功狀態只在 GitHub 回傳 commit 後顯示；連接成功不代表備份成功。
- 更新使用說明與各頁過時的「永不上傳」文案，清楚說明只有選配確認後才上傳。

沒有 Google／Microsoft 雲端登入、共享寫入憑證、背景自動備份或即時同步。GitHub 不會代為授權 Google Drive／OneDrive；這些服務需要另外註冊應用與供應商授權流程，暫以使用者手動保存下載檔處理。

本次不修改可攜式資料模型或專案檔格式。以模擬 GitHub API 測試權限、衝突、失敗與還原；未取得使用者實際權杖，不宣稱已在真實私有儲存庫完成 authenticated 端對端驗證。iOS／Android 實機的帳戶與政策差異仍需使用者實測。

驗證：185 項單元測試、12 項契約檢查、38 項桌面／手機瀏覽器測試、型別檢查及正式建置通過。GitHub 端點為測試替身；備份產生、格式驗證與本機還原使用真實流程。成功紀錄只保存目的地、修訂、時間及 commit，不保存權杖。
