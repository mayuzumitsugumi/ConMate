# v0.6.0：通販庫存對照

庫存頁新增網路商店數量對照，幫助攤主核對實體庫存和通販可售數量。

- 建立商店名稱、商品、出貨庫位及商店連結。
- 記錄各商店目前可售數量及核對時間；同商品同庫位會加總比較，顯示與帳面實體庫存的差額及超額警示。
- 可編輯、封存或恢復對照項目；封存項目不列入合計。
- 網店數量是手動核對紀錄，未串接商店 API，不會自動同步、預留或扣除庫存。
- 資料升至 schema 5，Excel 專案格式升至 2.3.0，新增有資料時才顯示的 `07_通販對照`。
- 匯入舊版 2.1.0／2.2.0 專案時安全補上空對照清單，不修改既有數量。

驗證：56 項單元測試、型別檢查、建置及桌面／手機通販對照流程通過。
