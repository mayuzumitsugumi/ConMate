# v0.4.0：專案檔檢查與本機還原

可將 ConMate 網站匯出的專案檔帶回網站。先選檔檢查並查看工作區名稱、資料數量及格式資訊，確認後才新增至本機；原有工作區永遠不會被同 ID 檔案覆蓋。

- Worker 隔離解析 XLSX，限制壓縮檔及展開後大小，拒絕公式、巨集、外部關聯、嵌入物件及不安全路徑。
- 驗證格式版本、SHA-256、payload 長度、資料欄位、識別碼及跨資料關聯。
- 原子新增工作區，確認前不更動資料；重複工作區 ID 或提交期間出現衝突都安全拒絕。
- 支援 ConMate 專案格式 2.1.0、資料 schema 3。舊版完整模板與手動編輯的日常工作表不是還原來源。
- 本機還原不等於雲端備份；匯入後仍建議保留原始檔。

驗證：41 項單元測試、型別檢查及建置通過；最新使用者附件完成解析、還原、再匯出與內容比對；Playwright 桌面及手機還原流程各一例通過。
