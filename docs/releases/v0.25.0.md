# v0.25.0：營運報表與顧客收退款核對

新增「營運報表」分頁，使用同一工作區的既有紀錄查詢，不新增或改寫交易、庫存、成本及備份狀態，也不需遷移資料。

- 依台灣成交日期選取銷售群組，可篩選活動、成交時創作者、商品目前企劃及商品，按四種維度分組。
- 原成交、退款／換購折抵、退款後營收、可售與損壞退回數分別呈現；所選成交包含目前快照中的全部關聯退款，即使退款發生在日期區間外。
- 成本採原批次／單件來源，精確分數先聚合再顯示四位小數，未知成本列未知；已知部分可核對，但不推算完整利潤或分潤。
- 實際顧客收退款獨立按每筆發生時間查詢。成交使用收到金額減找零，換購只列實際差額，折抵不當成現金退款；未記錄的退款付款人維持未知。
- 現存、預留、未預留及已標記單件數量供當下核對，依商品目前資料篩選，不是日期區間的歷史期末庫存，也不依活動推算歸屬。
- 提供六張純值 XLSX 報表：說明、總計、分組、銷售明細、現存庫存、實際收退。沒有專案隱藏技術表，不能用來還原專案；精確小數以文字保存，避免試算表再取整。

創作者使用成交快照，缺快照的舊紀錄列未記錄；目前沒有成交時企劃快照，所以企劃明確依目前商品歸屬。收退現金不按創作者／商品拆分混合交易，不推定退款由原收款者付款。活動費用、代墊、交款及成員分配不列入本次顧客現金表；報表不能當實際持款餘額或正式會計帳。

完整專案仍為 schema20／Dexie21／Excel2.18，既有備份與活動檔不變。
