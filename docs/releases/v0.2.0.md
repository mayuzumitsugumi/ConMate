# v0.2.0：先在網站填，再一鍵匯出

- 商品建檔分頁可新增、編輯、封存及恢復；商品名稱必填，其他資料可補齊。
- 周邊種類自由輸入，不要求使用者選固定分類或填new:。
- 自訂商品資料分頁可定義標記及六種額外欄位，選項有穩定ID；封存不丟失舊值。
- 商品、選項、關聯、封存內容保存於本機IndexedDB；遷移保留v0.1建立的工作區。
- 專案檔與備份分頁透過Worker匯出一份XLSX，只呈現有資料的商品／設定；完整當前建檔資料放同一檔案的隱藏技術表。
- 舊版66表模板移到進階入口，非主要建檔流程。

網站專案檔格式2.0.0與舊模板不同。匯入／還原、自動雲端備份、庫存、販售及財務仍未開放；匯出不代表已存入雲端或已完成可還原測試。使用者可以自行保存檔案，但不要清除唯一的本機資料。
