# v0.12.0：保存可靠性與操作效率

- 購物車草稿儲存在此裝置的獨立本機資料庫；離開頁面或重開後可恢復，已成交操作不會重複出貨。草稿不保留庫存，也不包含在可攜式專案檔中。
- 商品可搜尋名稱、種類、創作者及企劃；一次貼上多個名稱即可原子建立商品，明確限制筆數並回報錯誤。
- 下載紀錄與「使用者確認已保存」分開；資料更新或超過七天時提醒備份，不把發起下載當作檔案已保存。
- 同工作區還原先顯示新增、變更及移除數量，再明確確認取代，不自動合併。
- 取代時再次核對本機完整內容，預覽後有變更便拒絕；原資料與替換動作同一交易保存為本機復原點。修訂遞增使其他頁面舊寫入失效。
- 可檢視及取回本機復原點。本機復原點仍會隨網站資料清除，不取代外部備份。
- 提供瀏覽器儲存估算及使用者主動請求持久儲存；瀏覽器可拒絕，不能保證資料永不被清理。

可攜式資料仍為schema10／Excel2.8；Dexie11另增裝置本機復原點與備份狀態表。
