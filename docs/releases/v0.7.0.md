# v0.7.0：自訂庫存異動類型

庫存登記改以「增加庫存、減少庫存、移動庫存」為基本方式，也可建立自己的類型名稱，例如廠商到貨、送給朋友、帶去場次。

- 自訂類型可改名、封存及恢復；庫存變化方式建立後不可修改，避免改寫歷史的數量含義。
- 每筆異動保存當時類型名稱；改名不回溯修改舊紀錄。
- 舊異動紀錄、庫位與數量完整保留；沖銷仍新增反向紀錄，不刪除歷史。
- 資料升至schema6，專案格式2.4.0；可還原2.1.0至2.4.0，舊資料補空類型清單，不推算新紀錄。
- 新增「08_異動類型」日常工作表，隱藏系統表仍包含完整關聯。

庫存異動只記數量，不會因類型叫「售出」就自動建立營收。銷售及財務記錄仍須使用對應功能。
