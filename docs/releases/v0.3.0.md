# v0.3.0：企劃與場次分頁

本次完成一個可獨立使用的功能頁，不涉及尚未開放的收款、庫存或財務。

- 企劃：新增、編輯名稱及說明、顯示已連場次與商品筆數、封存及恢復。
- 場次：新增、編輯名稱、起迄日期、地點及備註；結束日留白則採開始日；拒絕無效日期及結束早於開始。
- 一個企劃可參加多場，一場可連多個企劃；使用穩定ID，改名不改商品或參場關聯。
- 封存不等於結案，不刪商品、參場關聯或款項。已連的封存企劃可保留或移除，但不能新連至其他場次。
- 商品頁不提供新增至封存企劃的選項，原有商品仍能保留其歸屬。
- 工作區資料隔離；寫入仍經同一原子交易與修訂檢查。

## 儲存與匯出

Dexie version3將v0.2網站建檔資料schema2升到schema3：保留工作區、商品、自訂資料、ID與修訂，補企劃說明／封存狀態，新增events及projectEvents。未知版本升級失敗不得刪庫。

單一專案檔升至2.1.0；有資料時增加03_企劃、04_場次日常表，全部穩定關聯仍在同一隱藏技術表。不新增每功能一個檔案，不輸出空白場次表。網站匯入／還原仍未開放。

個人GitHub雲端備份已正式納入規劃，但本版沒有授權、上傳或還原功能；見個人雲端備份決策。
