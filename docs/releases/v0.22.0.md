# v0.22.0：專用方案庫存預留

一般販售方案維持共用實物庫存。需要保留指定用途的數量時，可為方案、商品及庫位明確建立專用預留。

- 預留不增加實物，不重複扣除活動交付量；共用可售＝現存－尚未售出的有效預留。
- 同方案、商品、庫位只保留一份有效預留。專用方案只使用自己的剩餘配額，不會售罄後自動挪用共用庫存；先明確釋放才能重設。
- 其他指定／抽選、無料、損耗、調撥及一般沖銷不能挪用預留。方案封存、移除預留商品及商品封存前需先釋放。
- 原庫位的可售退貨或全額取消，只在原預留仍有效時恢復原配額。已釋放、退至其他庫位或不能再販售的退貨不會重建預留。
- 改價仍保留原預留；新增、釋放與異動使用保留歷史，還原會重播數量與對應方案核對。
- 活動工作台使用同一面板及規則。結案時明確提示並留下釋放原因；合回保留預留歷史與商品／方案對應，結案及實物退回不重複增加庫存。
- 完整備份升至 schema18／Dexie19／Excel2.16，舊備份及活動檔安全補空預留清單。活動格式仍為1.0，舊版網站不支援較新的資料版本時會拒絕，不會刪資料。

本階段不包含特殊單件序號追蹤、購物車暫占、網店自動同步或即時多人同步。下一階段依路線圖處理特殊單件。

驗證：269 項單元案例、12 項契約檢查、50 項桌面／手機瀏覽器案例通過。包括兩個專用方案合計不能超額、一般出庫不可挪用、部分退款原預留恢復、已釋放不重建、失敗交易回滾、舊活動續作版本相容，以及實際斷網的預留／販售／結案／合回完整流程。
