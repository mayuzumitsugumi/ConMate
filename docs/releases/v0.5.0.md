# v0.5.0：庫存異動

新增可追溯的本機庫存紀錄，先支援製作入庫及基本庫存調整。

- 建立庫位，記錄製作入庫、無料發放、損耗、人工增加／減少及庫位調撥。
- 以唯一庫存異動紀錄計算各商品各庫位的現存數量；調撥不改變總庫存。
- 錯誤異動透過反向沖銷更正，不刪除歷史；防止重複沖銷及負庫存。
- Dexie資料升至schema4，保留原工作區與商品；舊資料不會被推算出庫存。
- Excel格式升至2.2.0，增加有資料時才顯示的庫存及異動表。
- 還原相容格式2.1.0與2.2.0；2.1.0資料會以空庫存安全升級。

銷售扣庫、批次／保留、正式盤點單及財務尚未開放。

驗證：50項單元測試、型別檢查、建置及桌面／手機庫存流程通過。
