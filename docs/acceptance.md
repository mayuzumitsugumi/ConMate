# 驗收基線與需求對照

狀態：T01。這是後續實作驗收契約，非現有應用測試報告。

## 資料檔

- `tests/fixtures/contracts/workspace.json`：132列純虛構新資料、兩企劃／兩場、共用池、跨企劃銷售、退款、盤點及交接情境。參照尚未轉正式ID，可用來測試首次匯入；它不是可直接上傳的xlsx。
- `tests/fixtures/contracts/finance.json`：25個精確數值及政策驗收向量。分為使用者原表、對話已確認及純測試三種來源；synthetic不作合作預設。
- `docs/contracts/workbook.json`：66表、741欄的初始契約，包含57–61新欄位。
- `docs/contracts/issues.json`：錯誤／警告與修正建議。

## 狀態／儲存／交易驗收

| ID | 情境與預期 |
| --- | --- |
| APP-01 | 同operationId重送相同交易，回原結果、不重複扣庫；不同內容拒絕。 |
| APP-02 | 在寫交易／出庫／操作收據任一步模擬失敗，全部回滾，修訂與序號不前進。 |
| APP-03 | 草稿重開可恢復，不計營收與正式庫存；取消草稿沒有回庫分錄。 |
| APP-04 | 同工作區第二個可寫分頁被阻止；唯讀查詢可繼續。 |
| APP-05 | 遷移失敗原資料仍在，不能刪庫重建；未知新版不降級。 |
| APP-06 | FIFO跨兩批成本不同，出庫量與成本追到正確批次；退貨回原批次。 |
| APP-07 | 同SKU同購物車不同方案合計超量，整筆拒絕，不能前半筆先成交。 |
| APP-08 | 已分款交易退款形成追加差額，保留原確認與付款。 |
| APP-09 | 特殊單件不能重複位置／出售；共用商品不建立假單件。（P1） |
| APP-10 | 盤點截止前來源被更正，盤點needsReview；不靜默改已確認快照。 |
| APP-11 | 免費／損耗／寄賣移動均有正確類型；寄賣移動不是營收。 |
| APP-12 | 開攤或結案有未計算財務及未清款，警告可確認，不阻止有效操作。 |

## Excel 驗收

| ID | 情境與預期 |
| --- | --- |
| XLSX-01 | 空白模板跨表new:代號，任意排序仍解析為相同關係；缺參照定位到儲存格。 |
| XLSX-02 | 同名不同代號是兩筆資料；同實體重複代號拒絕，不自動改名。 |
| XLSX-03 | 自填未知ID、編號與ID不符、同ID兩列拒絕。 |
| XLSX-04 | 同文件再次新增拒絕；下載更新檔可繼續修改。 |
| XLSX-05 | 過期修訂及預覽後目標變動拒絕；不部分提交。 |
| XLSX-06 | 一般／shared／array公式、隱藏表及說明表公式均拒絕；字串'=1+1'原樣安全保留。 |
| XLSX-07 | 巨集、外部關聯、OLE、異常XML、ZIP重複／穿越、解壓炸彈安全拒絕且不連網。 |
| XLSX-08 | 含單位金額、文字數字、原生日期序號、0.2百分比誤用按格式報錯，不猜值。 |
| XLSX-09 | 獨立檢查、下載報告、中止解析都不改工作區。 |
| XLSX-10 | 完整匯出→乾淨環境還原→重匯出，正規化原始資料、ID、規則、歷史、計算一致。 |
| XLSX-11 | Excel與LibreOffice重存後通過；前導零、文字、日期與布林不失真。 |
| XLSX-12 | 相同來源重算不同報錯；只改計算結果警告後重算；直接改系統分錄拒絕更新。 |
| XLSX-13 | 範例模板只能建立示範或獨立工作區，不直接覆蓋正式資料。 |
| XLSX-14 | 報告包含等級／sheet／cell／field／rawValue／原因／建議，危險文字不執行。 |
| XLSX-15 | 使用者人工分配、未解盤差、未清款可完整往返，不被重算抹掉。 |

## 財務驗收向量摘要

FIN-01–05來源與公式核對；FIN-06–09尾差、正負取整與累計；FIN-10本金；FIN-11–13負值政策；FIN-14退款；FIN-15固定費不重複；FIN-16折扣；FIN-17人工差異；FIN-18–19回本；FIN-20未付款非本金；FIN-21無料；FIN-22分攤不平；FIN-23重複抵付；FIN-24成本扣除不等於少給成本回收；FIN-25人工結案。

這25項在T07完成時需全部轉成實作單元／整合測試，不能用「檔案能讀」代替數學驗證。

## T01 檢查方式與限制

執行 `python -m unittest discover -s tests -p '*_checks.py' -v`，僅用標準函式庫檢查JSON契約、參照、選項及人工數值向量的一致性，**不是**應用程式測試，也不安裝套件。

這些檢查通過只能宣告T01資料可互相核對。PWA、IndexedDB、財務引擎、XLSX往返及實機均尚未實作／驗證；不得宣稱T02–T15完成。
