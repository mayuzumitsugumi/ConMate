# 實作現況與後續順序（2026-11-03）

此文件依 v0.16 程式與既有討論核對，更新至 v0.22；早期 T01 契約是設計基線，不能直接當作完成狀態。網站先建檔已取代「先下載大型 Excel 模板」。

## 已有可用流程

工作區、商品與自訂欄位、多企劃與多場次、販售方案及跨創作者／商品混合抽選池、指定／抽選實際款式記錄、庫位調撥、盤點與待查差異、部分退款及可售／損壞退貨、成本試算與五種柄圖分攤、實付與代墊、明確來源分潤試算／人工決定／款項核對、Excel 驗證還原、購物車草稿、本機復原點、使用說明，以及選配 GitHub 權杖手動備份。

GitHub 實作是限定私有儲存庫的個人權杖連接，不是一鍵 OAuth 登入；實帳號憑證測試尚未完成。Google／Microsoft 授權沒有實作。所有基本功能仍可免帳號離線使用。

## 本輪新增：雙入口與活動交接

v0.21完成創作管理／活動工作台、分份交付、最小活動XLSX、離線續作、完整盤點及唯讀結案、範圍合回與實物退回確認。詳見[交接契約](decisions/activity-handoff.md)。交接配置不增加總庫存；v0.22另外提供同一活動份內的專用方案預留，兩者不重複扣量。

## 依序實作

| 順序 | 範圍 | 狀態與驗收重點 |
| --- | --- | --- |
| 1 | 入庫批次與 FIFO 數量來源追蹤 | v0.17 已實作。新入庫為獨立來源；調撥保留順序，銷售與一般出庫依 FIFO，退款／沖銷追到原來源。舊帳只標示來源未指定，不偽造歷史製作批次。v0.19另補明確的成本連結，未連結來源仍未知。 |
| 2 | 創作者與柄圖主檔管理、商品所有權 | v0.18 已實作獨立名稱／封存／作者關聯，商品擁有者與創作者分開；舊資料不推定擁有者或柄圖作者。新成交保留歸屬快照，舊交易維持未記錄。多人共同所有權比例與柄圖授權契約尚未建模。 |
| 3 | 批次成本連結與已售成本 | v0.19已提供明確同商品同數量的製作入庫成本快照，僅對連結後銷售生效，退回可售品用原銷售成本反向核對；損壞成本另列，不代決定損失負擔。舊來源及連結前銷售維持未知。成本修改以新版本生效，不重算舊銷售；跨多筆入庫分攤成本與回填舊交易更正另待擴充。 |
| 4 | 內部計價及約定回收 | v0.20已提供成本／柄圖來源快照、明確內部負擔、每件約定回收、差額歸屬與實收沖銷，新版本累計前版實收。未自動隨顧客銷售回收、抵付代墊或跨工作單自動計收；不把折扣或出資自動當欠款。 |
| 5 | 專用池保留與特殊單件 | v0.22已提供明確的方案／商品／庫位預留、專用配額銷售、退款回復與釋放稽核；一般池仍共用。活動結案釋放剩餘預留並合回歷史。特殊單件唯一庫位與指定單件出貨尚未提供，接續本階段部署後處理。 |
| 6 | 換購差額及現場效率 | 待實作。明確記錄實收／實退差額並連結原交易；不推定已付款。條碼、圖片及進階大量編輯屬後續效率擴充。 |
| 7 | 可外部編輯的精簡資料匯入 | 待實作。完整備份還原已具備；日常表編輯目前不匯入。先限定主檔新增／更新，暫時代號／穩定 ID、驗證報告與預覽提交，不直接改寫歷史交易。 |
| 8 | 寄賣及預售完整流程 | 延後。現有庫位能記錄地點，不等於寄賣交付／對帳或預售訂金／交付管理。 |
| 9 | 雲端與實機驗證 | 手動 GitHub 功能已提供；需真實私人憑證、iOS／Android、不同試算表重存及容量測試。OAuth 或 Google／Microsoft 需先完成應用註冊與授權設計，不暗中加後端或公開 secret。 |

## 不重新加入的舊方案

不要求使用者手寫 ID／new:、不以 Excel 列號作關聯、不提供只記抽數後反推每筆獎品，不把盤差當營收、不以未清款阻止結案。多人同步、複雜促銷、系統隨機抽獎及正式會計系統仍非本輪範圍。
