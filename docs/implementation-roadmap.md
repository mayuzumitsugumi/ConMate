# 實作現況與後續順序（2026-11-07）

此文件依 v0.16 程式與既有討論核對，更新至 v0.29 第一版驗收候選版；早期 T01 契約是設計基線，不能直接當作完成狀態。網站先建檔已取代「先下載大型 Excel 模板」。

## 已有可用流程

工作區、商品與自訂欄位、多企劃與多場次、販售方案及跨創作者／商品混合抽選池、指定／抽選實際款式記錄、庫位調撥、盤點與待查差異、部分退款及可售／損壞退貨、成本試算與五種柄圖分攤、實付與代墊、明確來源分潤試算／人工決定／款項核對、Excel 驗證還原、購物車草稿、本機復原點、使用說明，以及選配 GitHub 權杖手動備份。

GitHub 實作是限定私有儲存庫的個人權杖連接，不是一鍵 OAuth 登入；實帳號憑證測試尚未完成。Google／Microsoft 授權沒有實作。所有基本功能仍可免帳號離線使用。

## 本輪新增：雙入口與活動交接

v0.21完成創作管理／活動工作台、分份交付、最小活動XLSX、離線續作、完整盤點及唯讀結案、範圍合回與實物退回確認。詳見[交接契約](decisions/activity-handoff.md)。交接配置不增加總庫存；v0.22另外提供同一活動份內的專用方案預留，兩者不重複扣量。

## 營運報表進度

v0.25新增唯讀營運報表，按成交群組核對銷售、退款／折抵、原來源成本與未知數量；實際顧客現金收退依發生日期另列。創作者採成交快照，企劃只能依商品目前歸屬。現存庫存不是歷史期末庫存；損壞退回成本不自動當成損失負擔，報表不是分潤或正式會計帳。可下載純值報表，不能用來還原專案。精簡主資料匯入已支援主檔常用實體；仍需補試算表重存及大筆數驗收，圖片／條碼於v0.29補齊基礎辨識，寄賣／預售分別於v0.27／v0.28提供。

## 不重新加入的舊方案

網站建檔不要求使用者手寫 ID／new:；選用主資料匯入範本時，保留既有 ID，新增資料以代號建立跨表參照。不以 Excel 列號作關聯、不提供只記抽數後反推每筆獎品，不把盤差當營收、不以未清款阻止結案。多人同步、複雜促銷、系統隨機抽獎及正式會計系統仍非本輪範圍。

## 第一版候選版與發布門檻

v0.29完成最後一包商品效率：本機縮圖、選用條碼、查找後明確選品、低風險的備註批次修改。domain23／DB24／完整專案2.21與活動1.1，舊檔可升級；新版不讓舊版程式靜默捨棄新欄位。報表仍沿用既有已驗證查詢，不重寫帳務計算。

容量驗證有明確限制：500商品／20創作者／1,000筆虛構交易可完整XLSX→驗證→IndexedDB還原；10,000筆案例的報表及資料一致性通過，但檔案展開約42 MB，超出30 MiB。匯出與匯入一致阻擋超限檔，不下載不可還原的備份，也不把它標為已備份。圖片及其他內容會影響容量，這不是固定交易筆數上限。

第一版尚需使用者在主要裝置進行實機與實際試算表驗收。完成清單、問題回報格式及v1.0發布步驟見[第一版驗收與正式發布](first-release-checklist.md)。候選版部署不代表真機已通過；待使用者確認再正式發布，不重置工作區。

OAuth／Google／Microsoft授權、多人同步、自動雲端備份及其他已列出的進階擴充不阻擋本次第一版。GitHub私人權杖手動備份仍是選配且需使用者自己的帳號驗證。
